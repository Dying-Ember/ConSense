# 保留双解析证据并按完整结构选择规范输出

用户采纳：扫描区域保存两套完整解析结果与分歧；新增文件允许依据开发与文件级评价支持的通用版式特征，在区域或完整表格组粒度选择规范输出，保留来源与采用依据。该决策以质量优先为前提，接受额外解析、映射和验证工作，以利用经实测证明的互补能力；它替代“固定一套主输出、第二套仅提供分歧”的方案，不预设哪套在哪类更优。

表格按完整结构组选择，避免逐格拼接破坏行列、合并关系和表头归属。置信度更高或两套一致不直接作为正确依据；无法判断的局部保留未知。固定资料由 Codex 对照原件精修，新文件路由不能绑定已知页码、项目值或特定裁图位置。后续规范文本/结构及其向量版本须能追溯到所采用的解析结果，原始双输出继续保存。

目前接受的是设计决策；当前只修改文档，没有修改实现、运行模型或证明路由质量。
