# 不足依据的咨询保留经验证的有限分析

用户在 Advisory 能力对齐访谈选择 Q1=A：必要澄清尚未解决时，同一答复可以保留经验证的有据局部说明和真实引用，并明确不能定论事项及补问，整体仍保持 grounded=false／不足依据状态。此前整段清空会丢失可靠分析；直接放行模型正文又会混淆项目采用、有限解释与确定权利，因此发布必须按可界定的分析部分继续核范围、引用、采用与相关限制，不自动改成 reference_only 或把用户假设提升为合同证据。

该边界同时约束实时答复、流式发布及持久历史：保存应用实际允许交付的有限正文、补问与来源身份，最终成功须经过原有来源／会话／模型提交守卫。选择保留有限分析不表示当前代码、活动实例或真实模型已完成这些能力。
