# 按模板版次复用图谱基线，并保留原子识别

当上传模板与已有来源、版次和内容均已核对的图谱基线一致时，Drafting 优先恢复该基线并绑定当前原件；已核对的部分也可作为待审核草稿复用，缺失、差异和不确定之处保持待核。原子语义能力继续用于解释来源、核查疑点、识别变化和补充候选，不将每个说明或原子处理环节直接视为独立项目输入。

这样选择是为了保留多个来源和修改范围所共享的业务变量与完整条件链，避免同版模板每次从局部说明重新推断、再人工拼回共同变量。模型可按需获取固定图谱和当前版原文；它产生的归并、关系与范围仍是待审核草稿。人工可按版次整组确认有依据的部分，并先对已确认变量提取项目候选；未确认部分、项目取值采用和最终文件修改分别保留核对边界。图谱局部变更只使受影响的内容待重新核对，历史记录保留；明确标为模板版次适用的人工修正可供新项目待核复用，不携带项目答案。

条款版本与文件格式分开识别：同一套 SCC 条款可能以 PDF 或 Word 提供。跨格式复用前须核对内容和版次，逻辑基线可以复用，具体位置与可编辑范围必须绑定当前原件。两套 SCC 的条款编号差异明显，对应关系应结合原文、指导说明和结构核对，并分别保留各版编号及引用；不能因标题或编号相似而混用。

本决定记录已确认的设计方向，不证明现有基线完整、运行时已经实现，或真实模型及前端业务验收已经通过。
