## 目标与完成条件

以同一项目的 NTT／SCT／Word SCC 为第一组冻结来源，从全部编制要求、修改建议和处理点反推变量，形成带原证据的固定类型影响链，并合成可审计图谱。逐文件处理只是工作流分段，跨文件共享变量、前置、共同作用、引用和多处目标最终必须综合核对。PDF SCC 在解析交接中作为独立版本必测；当前模型开发回归先用 Word SCC，后续 PDF 试验必须独立来源／目标／评分，不能移植 Word 条号、默认或关系。

同时满足以下各门，才把 Goal 标 complete：

1. **来源门**：冻结原件 SHA／版本；全量处理点与原段分母有账；guidance、正文、续文、父子层级、布局与目标成员的来源准确。当前 97 guidance／194 段只是已提取 guidance 分母，不等于所有隐含处理点已完整发现。原文缺证与解析漏项分开。
2. **覆盖门**：每个已确认编制要求都有处置：形成变量／约束／动作／外部核查，或给出有来源的非变量理由。每个变量可追溯到要求与原文；每条影响链的全部已知输入、条件、前置、共同作用、派生输出、目标范围和动作有来源。不能用旧 79 字段或历史图谱代替发现分母。
3. **正确性门**：schema、ID、引用、类型和值状态合法；原文限定、否定、阈值、合取、例外和正负分支无关键错漏。变量到变量的边使用明确 output/input 绑定，不把自然语言 result 当作已实现的求值边。动作与准确范围逐项匹配，不把删短语、删引用、整组删除、Not used 和不采用混用。
4. **未知门**：项目值未给、外部正文缺失等真实 unknown 可以合法存在，但须明确所缺证据、受影响节点和安全后果。unknown 不能变 false／默认／known；不得把来源已给但未理解的规则藏进 unknown 来换绿。来源充分的关键规则与跨页完整组仍有未决时不授整体通过。
5. **稳定门**：候选方案冻结后，至少 3 次独立完整构图重复（新模型会话、同一来源／提示／参数，原始输出保留），均通过结构、覆盖及独立源核；规范化业务图的事实、条件、关系、动作和范围一致。措辞和程序分配 ID 可不同；不能从中挑最好一次。开发回归已暴露题与未参与该方案选择的验证来源／变体分开报告。
6. **回归门**：同一冻结分母的旧正确不回退；新问题可定位到首个失真阶段。代码自检、真实 API、来源准确、图谱语义和稳定性分别报告，模型自评不能替独立审核。

如果阶段仅产出正确局部片段，明确写“局部通过”，不得据此完成全量 Goal。真实模板编辑、页面布局导出质量和产品验收不属于本目标。

## 每轮固定流程

1. **回看累计证据**：读本 Goal、state、HTML 最近结论、所有失败及旧正确；按“来源／抽取／候选同义／条件／类型／动作范围／拼图／审核”归到首个问题层。
2. **先写再试**：登记本轮假设、一个主要变化、未变项目、来源与输入 SHA、对照模型、重复次数、评分分母、调用／生成／时间上限、停止条件。工作流整体换代属于一个主要设计因素，明确内部变化，不能据此声称某个 token 参数的因果。
3. **分工而不切断证据**：可以单文件抽原要求／事实卡，再综合；跨文件待判必须重新带回相关原文。模型每次只解决一个职责，程序承担 ID、来源回取、合法固定域和确定性引用维护。每个模型上下文独立；缓存不等于聊天历史。
4. **过门与隔离**：保存 raw／usage／finish；先做结构和证据定位，再做独立业务核对。失败节点保留并隔离，下游可接收明确的候选／疑点状态进行诊断，但不能把它当已确认事实。必需上游不完整时，受影响分支阻断；无关分支不必重跑。
5. **防止误差放大**：每个中间卡和链都带原证据及修订；复核时读原文，不只读前轮摘要。禁止静默覆盖已确认字段；delta 有明确读写集合、旧值、新值、证据和原因。程序重算完整静态依赖的失效范围，包括当前关闭／未选分支；保原始图和回退版本。
6. **收口再设计**：把本轮改动、卡点、实际改善／回退、调用／token／耗时、未执行和下一轮决策写入同一 HTML，再冻结下一轮。只有新变化才重新测试；不为了碰运气重复同配方、删断言或缩分母。

变量取值验证使用独立测试场景，不写真实项目采用值：布尔true／false／unknown，choice每个有源分支及Other，AND前提逐个缺失，数值阈值前／等于／后，集合空／单／多成员，invalid与人工采用冲突分别测。比如39月阈值、首12个月范围要按原件条件预冻断言，不能把历史代码答案当gold；每个场景核产生的派生变量、联动决定与完整目标组。修改上游值时，要证明旧链失效和新链重算，不能让上一轮生成的内容累积成为新证据。测试仅用伪目标编号，不生成真实替换段落。
