## 1. 要解决的问题与可反驳假设

目前的 `scope/conditions/result/missing_evidence` 减负输出没有证明能恢复完整类型链。两个 AND 区块引入 descriptor 与输入 guard 的歧义；自由文本 result 也不能唯一恢复值域、配方、输出引用、采用或动作范围。旧字典 SHA 不变和 190 个定义能映射八值型，只是库存事实，不是无损覆盖证据。

本实验比较以下工作流：模型只承担声明、真实条件、有限类型效果和缺证的语义职责，程序通过已有 typed contract 生成唯一确定的登记标签、ID、依赖、状态政策和图封套。必须由原文判断的含义仍由模型明确表达，程序不得临场阅读 instruction 猜动作。

预声明假设：

- H1：在一个已明确定义的窄 profile 内，紧凑对象可通过实际编译、往返和反例求值，完整保留必要语义。任何字段丢失或两种不同含义编成同一条链，即推翻该 profile 的 H1。
- H2：同一开发证据包下，M2.7 或准确型号 M3.1 能一次输出原样可解析、来源等价且能实际编译求值的候选。两者全保原结果，不取最好片段拼成成功。
- H3：选定候选在冻结的新多题挑战包中，三个独立会话均通过相同门。任一关键漏项、反向、额外限制或不安全动作即失败；3/3 只支持本地 profile 的这三次观察。
- H4：局部可靠后，真实跨文件薄链能在已闭合的来源与采用证据下保持输入输出和范围。缺原件范围证据则保持未测，不以伪目标通过授予 H4。

这轮是工作流／系统候选比较。M2.7 的既有默认 thinking 与 M3.1 adaptive（未传 effort，按冻结官方说明为默认 max）不同，不能声称纯模型能力或单个参数的因果比较。不继续重复 P1210 调试。

## 3. 紧凑契约及责任边界

模型侧语义对象只含职责不同且有固定 shape 的四部分。具体版本在调用前冻结为可执行 schema 与示例，不能仅用本段自然语言授予执行能力。

| 区块 | 必须表达 | 程序可确定的部分 | 禁止的捷径 |
| --- | --- | --- | --- |
| declarations | 局部 handle、含义、project input／adoption／output／source descriptor 等角色，八值型，必要的单位、闭域、成员 schema、原证据 | 全局命名空间、源修订封套、确定 ID | 把 descriptor 当项目输入；把 record/list 变 text 或任意 JSON；补未给的项目值 |
| when | 一个有限有类型 AST，实际 subject、条件操作、typed operands、完整合取／析取／否定及证据 | 既有 registered predicate、依赖和固定状态政策 | 两个含义重叠的 scope AND；把输出用途先变成输入要求；把外部权威名称当实际值 |
| effects | 有界 variant：有类型派生／域输出、use-as 的输出角色、核查、结构／引用与候选编辑；显式输入输出及精确目标证据 | 唯一可导出的 R/I/C 等标签、读写集合与既有 L/T 图封套 | 自由 result 文本充当执行器；隐式采用；删短语与整组 Not used 混用 |
| needs | 缺来源与缺项目值分开、缺什么、影响哪些节点 | 固定 blocked／unknown 传播 | 以 unknown 掩盖原文已有但没有提取的规则；模型授予 actor／adopted／applied 权限 |

无来源支持的负向动作，只表示本正向贡献没有产生；不得自动推出删除、不采用或默认。未知、无效、冲突、inactive 及外部采用权限沿已有解释器，不能由模型写自由政策。

八值型与完整后台 V/P/R/I/C/F/D/A/E 能力保留。支持哪个 profile 必须逐项证明；未定义的复杂成员 schema、接口或动作明确 unsupported。支持子集过门，只准入该子集的模型实验，不得把局部门称为全 190 定义往返通过。

## 6. 比较、等价与评分

每份输出按六维分别报告，不能合为一个“模型不理解”的数字：

1. **来源含义**：每条预冻义务的主体、限定、数值、否定、合取、外部引用、动作与范围保持；有逐条 pointer。
2. **额外推断**：无源输入 guard、反向动作、默认、采用或项目事实；descriptor／guard 解释不唯一单列未决。
3. **原样语法**：严格原 JSON，拒重复 key、NaN、fence、null、截断，不修复后记原样通过。
4. **结构**：当前精确 schema、八值型、引用、单位、闭域、完整 shape；未知结构 explicit unsupported。
5. **编译**：实际生成旧 typed 链并经既有 validator 与 assemble；未执行不得叫可消费运行通过。
6. **实际求值**：独立项目反例、边界和 unknown／invalid／conflict／adoption 结果；记录未执行及不适用原因。

等价事先定义：允许局部 handle、登记 ID、无业务作用的节点顺序和自然语标签不同；允许可证明等价的有限 AST。主体角色、值型、单位、开闭边界、域、输入输出绑定、采用政策、动作粒度和完整目标必须相同。无法证明的等价保 unresolved，不人工作弊归一化。

每个包派发前另行冻结精确支持 profile、固定题 ID 集合，以及每题六维的 PASS／FAIL／N/A 规则和预期状态。真实缺来源／缺项目值所产生的合法 unknown 不算抽取语义失败；实际求值须得到预冻的 pending／blocked 及影响节点，才能授该层通过。未执行依然标未执行，不反推模型语义失败。unsupported 题不得在看到输出后删除或移出分母；若必要题型不受支持，先补离线接口或停派。X02 的执行通过必须附实际代码、运行回执和结果，引用旧解释器或文字描述不算执行证据。

稳定比较针对规范化的业务结果、条件与状态；canonical JSON hash 相同只证明字面相同，不独自证明来源正确。相反，hash 不同也不自动判语义不同。开发回归已有正确必须保留；改错与回退逐条并列。

P1210、Bill、METHOD、TSW 都是已暴露开发集。三份 Word 全文历史上也已暴露，独立挑选的新题只能称“历史暴露来源上的新挑战”，不是新文档 holdout。PDF SCC 已参与设计，也不自动变成盲测。真正新来源泛化、实际 27B／H800、全图三次重复保留为后续门。
