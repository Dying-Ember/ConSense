- 点击正文真实引用编号或其引用按钮，使用该条历史消息的证据身份选择固定／项目来源，自动读取完整源文件并定位。下载、加载、解析、定位错误与来源失效给明确状态；切答案、项目或会话时丢弃迟到响应并释放旧资源。
- PDF 复用已有 PDF.js reader，按已核原件 SHA、实际物理页及可验证位置跳转；有可靠坐标时高亮，无可靠坐标时仅定位真实页并说明限制。支持前后翻页阅读父条、邻文及完整相关表组，不从打印页号或条款编号猜物理页。
- DOCX 复用 JSZip／Mammoth／DOMPurify 阅读能力，以原件 SHA、partName、命名空间和完整 native path 唯一映射实际段落／表格／单元格；保留整表和上下文，不按相似文本找第一个命中，也不伪造 Word 页码。实际引用涉及其他包部件时，补齐该部件读取和定位，不能静默映射到主文。
- 复用原件读取的字节、版本与存储边界校验，并补 Advisory 当前模块／范围准入。不能直接借用 Vetting URL 就跳过 Advisory eligibility。阅读源文件不改变检索范围或项目采用。
- 主验收覆盖实际 PDF／DOCX 来源。原始 .doc 等尚无可靠 reader 的类型必须明确列为未支持定位，不以上传／后端解析成功宣称前端已支持；如实际验收材料包含这些类型，实施阶段必须完成相应可验证阅读路径后才能关闭该项。

### D. Codex 风格交互与真实流

- 提交后立即显示用户消息及接收状态，随后依据实际操作反馈范围／来源确认、检索、组织上下文、预算、生成、引用与答复检查、保存等阶段；显示真实耗时或可核数量，不模拟百分比，不将模型内部五步写成已经分别观测完成。
- 新增最小业务事件通道，保留现有同步 ask 的调用兼容；沿用项目／session／scope、viewEpoch、askSequence 等身份保护。POST 流需保留模型选择 header，不能用不支持这些 header 的 EventSource 偷换请求契约。
- 完成真正的正文分段流：模型传输支持真实 streaming，内部答复协议提供可完整解析、独立检验证据与限定的答复单元；通过相应门后才能发送该单元。只把完整答案字符串切块或打字显示不满足本项。某一路模型暂不支持时明确说明本次只有状态流与最终答复，记录正文流未完成，不宣称完整验收。
- 当前模型选择存在 ThreadLocal；在请求线程捕获 profile，并按已有 bind 方式在工作线程恢复／释放。异步化不得退回其他模型，也不得失去来源、session revision 或提交守卫。
- 支持当前请求停止、重复提交保护、错误／断线明确终态及人工重试。停止需取消可取消的本请求工作和输出；远端无法确认已取消时准确说明。取消／失败不写成完成答案，不停止共享模型服务或其他工作。
- 流式输出保留表格、Mermaid 及引用的完整单元，不渲染截断代码块；用户向上阅读时停止自动追尾，提供回到最新内容操作。最终成功事件必须在来源／会话／模型复核和原子历史保存成功后发送；部分发布后全局失败须显式标记失败或失效，不能保留“完整答案已完成”的观感。

### E. 自然问法与 T6 流程图 harness

- 用户自然问题驱动题型与模板选择，原始问句原样保留；详细的应用契约、文件范围、专家规范、T6 图规范由 harness 提供。不能靠前端 quick-question 塞一段强提示，或只在测试请求手工附全部规范才过题。
- T6 由已核文字组织起点、分支、行动人／接收人、动作、时限与起算、结束及真实失权条件。每条关键路径能回查真实条款／限定，不补造日期、期限、DRA／DARA 制度、失权或“较早者为准”。未知保持明确待核节点或有限文字说明，不能让图表示确定结论。
- 最小内部接缝优先采用同次结构化返回的小型图计划：节点、边、条件／动作、真实引用，以及出现时的期间与起算。应用校唯一节点、边端点、相关分支和引用，再确定性生成受限 Mermaid；不新写完整 Mermaid 解析器，不按题号或参考答案特判。图作为完整独立单元核验后发布，不能先流出半幅未验图。
- 复用现有受限 Mermaid flowchart、安全渲染与引用点击能力；合法 JSON 转义、节点／边完整性、语法和实际渲染均检查。图节点或关联说明中的证据可打开本次源文件。合同流程正确性与 Mermaid 语法／渲染成功分开验收。
- 输出不完整或校验失败只允许一次针对错误的修复，与既有 JSON 修复共用总预算，不叠加成“JSON两次＋图两次”。修复继续绑定同一来源、范围与模型，并重新核当前身份及预算；仍失败则明确图未完成，保留可靠文字与失败记录，不携带评价答案，不展示错误图完成。
- 官方问题 1.6 采用 question-only 输入，配套答案／流程图只在独立评价端。增加至少一个自然简短问法和一个缺日期／缺制度条件的变体；不得把官方答案、逐题期望路径或人工修订图送进同题生成上下文。
- 同步验收采集器：现有 `official_business_capture.py:254–267` 主要识别独立 flowchart 对象，需识别真实交付协议中的正文 Mermaid／图计划，避免将已渲染图误报 unsupported。实际安装 Mermaid 的 parse／render、浏览器可读性及独立原文路径核对分别保留证据。
