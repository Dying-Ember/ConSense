## Public seam for A08

```java
DraftPdfRenderProfile profile = DraftPdfRenderProfile.libreOffice(
    Paths.get(explicitConfiguredExecutable), Paths.get(privateWorkRoot), 120000);
DraftPdfConversionResult result = new DraftPdfConverter(profile).convert(exactGeneratedDocxBytes);
byte[] pdf = result.getPdfBytes();
String docxHash = result.getDocxSha256();
String pdfHash = result.getPdfSha256();
String profileHash = result.getRenderProfileHash();
Map<String,Object> provenance = result.getManifest();
```

The general `DraftPdfRenderProfile` constructor accepts an explicit argument-array command, work root, timeout, process-output and PDF limits, font-family inventory and its identity. The LibreOffice factory requires an executable path; it does not search PATH, download/install software, enable a service or choose a fallback. All callers must handle `DraftPdfConversionException.getCode()` explicitly. Its codes distinguish unavailable configuration/runtime, invalid DOCX, missing/unresolved active font capability, timeout, renderer failure, no output, corrupt/empty PDF and oversized output. No code path calls the plain-text Word/PDF writers.

`convert` clones its caller's exact bytes, inventories their source capabilities, writes those unchanged bytes as `artifact.docx` in a unique directory, and supplies an independently unique `-env:UserInstallation` URI. It obtains the renderer's actual `--version`, then invokes headless `pdf:writer_pdf_Export` with `ProcessBuilder` argument arrays. Version and conversion share one monotonic request deadline. Captured output is byte-bounded while the pipe is drained; output PDF size is checked before reading. PDFBox must reopen a non-encrypted PDF with at least one page. The private input is hashed again after conversion so a renderer that rewrites that frozen working copy cannot succeed.

PDF bytes are returned as defensive copies. Provenance includes exact input/output SHA-256, actual executable/version, stable render-profile hash (command, executable digest, version, filter, adapter version, locale, blank-profile policy and configured font inventory), unique private-profile/work directory, PDF page count/font names and embedded flags, and explicit font/field states. Profile identity does not include its random directory; concurrent conversions with the same settings have the same profile hash and separate workspace identities.

The code compiles to Java 8 class-file version 52. A renderer that may spawn children needs runtime ProcessHandle support to enforce the owned-tree timeout; Java 8 runtimes lacking it receive NOT_CONFIGURED **before** launching anything. The accepted local runtime is JDK 17. Shutdown uses only handles belonging to the started process and its descendants; it never kills by global executable name. A test keeps an unrelated renderer alive during the owned child timeout.

Private conversion directories are intentionally retained for diagnostics by this utility, including failures. A08/the host must define their scoped retention after immutable artifact publication. This ticket did not perform workspace/profile cleanup, start services, use databases/browser tools, or push code.

## Font and field boundaries

The source inspector applies ZIP/XML bounds (128 MiB per entry, 32 MiB XML, 256 MiB inflated total, 5,000 entries), rejects duplicate entries and external XML entities, and requires an editable DOCX package. It inspects document/header/footer/footnote/endnote runs, paragraph/character style inheritance and document defaults. Only script slots used by actual text, explicit symbols, and existing OMML text require corresponding font families. Unused theme/font declarations are separately inventoried. Missing active families or unresolved active assignments fail explicitly.

Installed family availability is **not** a proof that LibreOffice selected the intended glyph/font for every run. The factory's inventory is the JVM-visible OS font-family list; its fingerprint captures that family set, not font binary versions. Deployments needing stronger renderer/font reproducibility should provide a separately measured font inventory identity. PDF font names/embedding are recorded, and `fontSelectionStatus` and renderer glyph coverage remain UNVERIFIED. The final source PDFs use STZhongsong alongside Times New Roman in NTT/SCT and NotoSerifSC-ExtraLight alongside Times New Roman in SCC; these additional families remain a specific final QA concern, not silent certification of no substitution. Conditional table styles, advanced script/theme selection and exhaustive glyph mapping are not certified by the inventory.

`fieldStatus` always remains UNVERIFIED. The adapter never mutates exported DOCX field caches, and a returned PDF does not establish TOC/PAGEREF refresh. The actual source inventory finds 0 instructions in NTT/SCT and 99 instruction/simple-field nodes in SCC across body/footer parts. Root's independent reference QA identifies stale original TOC caches; this converter does not repair or certify them. A08 must surface this separate field state.
