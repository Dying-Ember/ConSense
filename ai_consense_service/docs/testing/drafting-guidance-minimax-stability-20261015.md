# Drafting guidance 联合流程：MiniMax 首轮稳定性试验

开始：2026-10-15；执行跨至 2026-10-16，Asia/Shanghai。原始时间、请求、响应和失败在忽略目录 `.local/drafting-guidance-stability-20261015/`。本文不保存原件、密钥或完整运行响应。

## 业务范围与判定方式

本轮依用户要求，将 NTT、SCT、Word SCC 视为同一项目的联合输入。修改要求先综合反推共享变量，并保各自多对多来源；不能按文档边界拆断变量及跨文件引用。PDF SCC 暂不参加。仅以程序声明的伪段落／目标标识检查语义意图，不生成或采用完整真实改文。

固定类型词表沿用 [typed graph 设计](../specs/drafting-typed-graph-workflow-20261015.md)。首轮不把现有图谱答案喂给模型。独立原文审查与模型自己的复核分开，JSON 合法、note ID 齐全或候选变量数量都不等于语义正确。

稳定性指每个模型对同一份联合输入开两个独立会话。比较输入字节、结构、来源、类型、条件、分支和跨文件关联；名称或措辞变化单列待核，不直接判为业务错误或正确。两次重复仅是首轮信号，不构成统计可靠性证明。

官方 `/v1/models` 已实际返回 `MiniMax-M2.7`、`MiniMax-M3`。调用直连官方，不经产品、活动项目或 LAN relay；没有自动重试、自动参数回退或重发失败序号。请求不保存 Authorization，响应按实际凭据脱敏。

## 验收边界

本轮已结束：2个模型×2版输入／提示×每版2次独立会话，共8次生成，严格自动消费通过0/8。3次超时、2次length截断、2次原始JSON／封套失败、1次JSON完整但来源／引用契约失败。此计数不是模型语义准确率，不能把超时或预算不足算成已证实的理解错误。3次超时的实际供应商用量未知，不能记为0；已收到usage的5次合计245,319输入、135,238生成、380,557总tokens。

第一道自动消费及稳定性门未通过，已停止新增调用。失败与诊断副本分别保存；不把恢复JSON、默默取最后一个重复键、跳过来源断言或模型自评通过算为原响应通过。未形成两份完整有效归集结果，后续原子拆解、合图、集中复核与重点回查均未执行，不能用拟议阶段充当实际运行。

后续任务边界建议：三份guidance继续联合归集；先保逐条要求和局部候选，别让单次输出同时负责全局同义合并、所有引用重写及双向来源表。模型另给可审的alias决策，由程序统一重写引用；反向来源表由要求→变量的正向关系计算；准确引文由已验证的来源ID回取，减少模型重复抄写。每变量／完整语义簇的类型、条件和动作仍在独立上下文中核验。以上仅为下一轮设计建议，本轮没有改产品或再跑一轮来授绿。

没有运行Qwen27B、GPT-5.6 Luna、PDF SCC、真实模板编辑、OCR、索引、产品写接口、数据库写、活动服务变更或H800部署。M2.7或M3的结果不能单独证明Qwen27B的能力排名或通过状态。
