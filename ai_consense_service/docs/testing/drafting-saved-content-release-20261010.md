# Drafting 保存正文与审阅一致性发布

本次提交发布本机已经实施的 Drafting 内容执行与审阅修复，并包含此前已授权但尚未提交的识别回归增量。本轮没有重新调整变量识别 harness、模型预算或用户确认值。未完成的 OER 接线在工作区另行推进，没有加入本次发布。

确认值必须落实到实际 DOCX 正文，修改计划、执行状态、保存定位和前端审阅使用同一份实际修改记录。指导说明清理独立记录为 editorial 操作，不能把删除说明报成整个业务条款已修改。审阅位置标签优先采用已经核验的保存定位及其业务操作；多重关联保留歧义，不选最近、第一或最后关联。

本次包含 Bill 编号及名称写入的来源身份校验、已采用内容与发放用途分支的区分、原生 DOCX 空白行兼容校验，以及源模板全文与实际 OOXML 来源一致性的校验。不能用另存的扁平模板文字替换原 DOCX 格式，也不能因纯空白单元格导致正确原件误报为文字分歧。

SCT 指导说明按完整条款范围执行：site formation 明确为 false 时，将 SCT6(1)(c) 及其三个子项处理为 `(c) Not used.` 并清理所属说明；domestic 条件作用于完整 SCT6(2) 和 SCT6(3)(c)，façade 条件只作用于相应付款短语。未知条件保持 pending，不推定为 No。来源版本和边界不匹配时拒绝自动写入。这些规则的当前精确来源核验不等于新模板自动适应已完成。
