## 镜像内外接缝与最终收口

每票检查其涉及的数据生产者和读取者、宿主与容器路径、实际权限及临时目录、版本和输入输出身份。接口错误、逐段输出、停止、结果落盘和容器退出后的可读性必须沿真实调用链验证。完整关闭条件统一维护在 spec 的“本机实机预演与关闭条件”中。

最终票只有本机真实 Docker 容器使用外置业务／前端／Python／配置、持久数据库、原件历史与稳定 OCR、embedding／rerank 实际权重完成试运行才可关闭；Qwen 以明确标记的占位文件和协议替身检查接线。替身不能证明真实 Qwen／vLLM 推理、计数、质量及赛方验收，均另记未验。宿主业务进程、内存数据库、文件存在与健康检查分别记录为局部证据。本机与 H800／赛方平台差异独立列出。

本次各票共同维护人手可执行的准备、启动、配置生效、状态检查、按编号找日志、排错、停止、换版和恢复步骤，并用实际执行验证。spec、票据及操作说明留本地与远端仓库；私有资产和证据留忽略目录。既有活动服务及数据先保护，用一致性副本和自有实例预演；此前取消的旧待办与质量整改不恢复。
