# 10: 离线修改代码并产出可运行的新版本

**What to build:** 在本机按比赛条件离线修改后端、网页或项目脚本，构建并登记完整新版本，容器读取新文件后能观察到实际改动，无需重做运行镜像。

**Blocked by:** 02 — 从硬盘启动后端和完整网页；03 — 从硬盘运行资料服务并读回历史资料；04 — 从硬盘执行显卡任务并统一控制占用。

**Status:** ready-for-agent

- [ ] 准备与本机实际容器运行环境兼容的离线构建工具和依赖，断网后分别完成后端与完整网页构建；项目脚本及资源也纳入发布身份。
- [ ] 分别做一个有限、可撤回的后端、页面、资料脚本和任务脚本改动，按各自构建、重启或新任务方式运行，实际界面或结果能够证明新版本已生效。
- [ ] 构建和运行不依赖隐藏的宿主程序、Windows 专属缓存或临时联网下载，不以第六个构建容器绕开数量限制；实际系统依赖与本机条件记录清楚。
- [ ] 形成独立完整发布版本和清单，保留源码、产物、脚本、配置及模型引用对应关系；运行目录不原地覆盖，旧版本保持可恢复。
- [ ] 实际启动入口、相邻导入、子进程和网页分包均使用正确版本；缺文件、混版本或清单不符时拒绝启动，业务资源不按说明文档扩展名误删。
- [ ] 在本机真实容器中打开新版本页面并完成已有请求，核对所用镜像未因业务修改而重制，结果写入预演专用持久数据。
- [ ] 写出人手可执行的离线修改、构建、登记、启动和校验步骤并实际照做；保存检查及运行证据，说明文档继续留在本地与远端仓库。
