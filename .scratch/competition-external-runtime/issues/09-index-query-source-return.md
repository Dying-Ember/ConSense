# 09: 让新资料完成建索引、查询和原文回查

**What to build:** 新资料的实际处理结果经外置检索链进入持久索引，使用者从现有页面查询并打开正确项目及版本的原文原页。

**Blocked by:** 08 — 用外置稳定 OCR 完成一次新资料处理。

**Status:** ready-for-agent

- [ ] 使用前票真实资料及处理结果，在本机实际容器中加载已采用的 embedding 和 rerank 权重执行建索引与查询，不用预填结果或内存替身完成本票。
- [ ] 资料服务、任务程序和持久向量数据库看到的源文件、解析结果、切块、模型、分词器、向量维度和索引身份一致，登记真实输入输出关联。
- [ ] 从现有浏览器入口查询，返回引用能够经后端打开对应项目、角色、版次的原文和物理页，历史与新上传资料不混用。
- [ ] 原有项目范围、来源采用关系和空模板隔离继续有效；不能通过另建重复索引或平行资料模型绕过现有约定。
- [ ] 重启所属资料、任务及数据库容器后，已保存索引、来源映射和引用仍可访问，路径变化不破坏历史关联。
- [ ] 模型或维度不匹配、索引版本错误、缺文件、结果持久化失败和取消时明确失败，不将空结果当作已完整检索。
- [ ] 保存真实权重加载、索引写入、查询、原文回查和重启重读证据；检索链可运行与召回质量、模型理解及业务判断分别报告。
