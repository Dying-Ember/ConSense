# 08: 用外置稳定 OCR 完成一次新资料处理

**What to build:** 新上传的代表性资料经实际容器链使用当前已采用的稳定 OCR 与外置真实资产处理，原始证据和采用依据在任务退出后仍能回查。

**Blocked by:** 03 — 从硬盘运行资料服务并读回历史资料；04 — 从硬盘执行显卡任务并统一控制占用。

**Status:** ready-for-agent

- [ ] 从现有业务入口上传一份授权的代表性真实资料，在本机真实容器中使用当前已采用的 OCR 权重与配套文件执行；不引入换型、训练或已取消的质量整改。
- [ ] 上传原件、实际处理的物理页、任务和解析输出保持对应，记录源文件哈希、页映射及实际模型与代码身份。
- [ ] 原有两路完整 OCR 原始输出、分歧和区域或完整表格组的采用依据继续保留，未知部分保持未知，不为拼接接缝而改写原始证据。
- [ ] 各进程通过登记路径与权限访问同一输入，输出写入持久目录；任务容器退出及所属服务重启后，两路原始结果和原页仍能读回。
- [ ] 图纸继续依现行文件身份规则识别标记后排除，不送图纸 OCR 或 CAD 解析；资料范围及既有排除项不扩大。
- [ ] 缺模型文件、页身份不符、写入失败、取消或崩溃都留下真实失败记录，未完整保存的证据不能授权成功或下一个阶段。
- [ ] 保存真实 OCR 执行及页面回查证据，并单独记录软件检查与原件质量结果；运行完成不自动表示识别质量或完整业务已验收。
