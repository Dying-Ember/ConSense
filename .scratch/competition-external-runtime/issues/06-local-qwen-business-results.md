# 06: 核验 Qwen 接口业务请求与持久结果

**What to build:** 在真实容器链中，以明确标记的 Qwen 协议替身发起普通和结构化业务请求，并在真实持久数据库保存和读回；真实 Qwen 推理及业务质量保持未验。

**Blocked by:** 02 — 从硬盘启动后端和完整网页；05 — 配置 Qwen 占位并核验兼容接口。

**Status:** ready-for-agent

- [ ] 在当前本地项目的一致性隔离副本上，从现有业务入口发起代表性的普通与结构化请求，经登记的实际容器链接入明确标记的替身。
- [ ] 保留项目、来源范围、任务、输入及版本身份，结果对应原请求及替身任务；替身结果不得被报告为真实 Qwen 模型业务结果。
- [ ] 现有结构化验证、错误处理和来源守卫保持有效；未通过验证的内容不能当成成功结果保存或展示。
- [ ] 成功、错误、超时及格式失败经业务接口和页面保留正确含义；不静默切换外网，也不将底层失败包装成空的成功回答。
- [ ] 成功或失败结果及完成状态写入选定持久数据库和证据位置，重启所属容器后通过页面读回；记录请求响应身份、替身标记和数据库重读证据。
- [ ] 保留本次改造引入退化的失败与修复证据；基线原有质量缺口和真实模型验收保持原状态。
