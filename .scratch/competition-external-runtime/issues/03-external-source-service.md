# 03: 从硬盘运行资料服务并读回历史资料

**What to build:** 外置资料服务继续通过现有业务入口提供历史原件、原页、规范来源和已有索引读取，使用者能打开正确项目及正确版本的依据。

**Blocked by:** 01 — 确定本次保留的行为和本机实际运行方案。

**Status:** ready-for-agent

- [ ] 本机真实容器从登记的外置项目文件启动资料服务，启动定义、模块导入、动态资源和子进程使用同一版本，不只修改镜像定义。
- [ ] 后端、资料服务及任务程序通过各自容器内路径读到同一份历史原件，内容哈希、项目、角色、来源版次和采用状态一致。
- [ ] 对隔离真实项目副本，通过现有页面和接口读取原文、原页、规范来源及已有索引；统一入口中基线已有能力全部保留。
- [ ] 历史绝对路径采用经验证的挂载或安全映射；缺失、错误映射、跨出允许目录及权限不足均明确失败，不悄悄读取替代文件。
- [ ] 只读发布资产、可写资料状态和临时文件位置符合实际权限；容器重启后历史资料、来源身份和既有任务记录仍可读取。
- [ ] 项目资料、起草空模板及不同项目的权限和索引范围保持隔离，不通过复制或重建新资料模型绕开现有来源约定。
- [ ] 保存实际文件对应、接口结果、浏览器回查和重启重读证据；列出资料打不开时可由人手依次检查的路径、权限、版本和服务状态。
