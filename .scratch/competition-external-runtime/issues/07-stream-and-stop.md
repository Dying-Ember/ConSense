# 07: 让本地回答逐段展示并能真正停止

**What to build:** 使用者在现有页面逐段看到本机 Qwen 的回答，并能停止自己的请求；断线、超时和停止后的历史状态真实可查。

**Blocked by:** 06 — 让本地 Qwen 完成现有业务请求并保存结果。

**Status:** ready-for-agent

- [ ] 用本机真实模型请求，观察逐段正文从模型、协调、业务接口和实际网关到浏览器连续到达，不能以最终一次返回或状态轮询冒充逐段输出。
- [ ] 页面明确区分执行中、正常结束、停止、断线、超时和失败，事件、错误及结束标识不被中间程序吞掉或改变含义。
- [ ] 从页面停止请求后，停止信号传播至实际模型任务，仅处理所属任务和进程；核对执行退出及资源释放后才能放行后续显卡任务。
- [ ] 浏览器断线、业务超时和中间程序异常均有有限清理行为，保留失败状态，不留下无人拥有的任务或无限等待。
- [ ] 经原有验证允许交付的部分正文、引用和不足状态正确保存；刷新页面或重启所属容器后，历史不会将部分结果伪报为完整成功。
- [ ] 实测停止不会终止其他请求、资料服务或无关活动实例，整个过程符合五容器限制。
- [ ] 分别保存真实流式、停止及持久历史证据和软件异常分支检查；补充人工判断网关缓冲、断线及停止未生效的方法。
