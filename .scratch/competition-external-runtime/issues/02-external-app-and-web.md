# 02: 从硬盘启动后端和完整网页

**What to build:** 使用固定运行镜像读取硬盘上的后端程序包、完整网页和实际配置，打开现有页面并执行一个已有业务操作；业务修改不再要求重做镜像。

**Blocked by:** 01 — 确定本次保留的行为和本机实际运行方案。

**Status:** ready-for-agent

- [ ] 在本机真实容器内启动后端和网页，使用登记的外置发布资产与实际配置；记录镜像、源码、构建产物和有效配置身份，不以宿主直接启动替代。
- [ ] 在 Docker 镜像准备具名非 root 运行账户，记录名称、UID/GID；核验实际进程身份、只读版本挂载与可写临时目录并验证页面、静态资源和业务接口。程序实际读取的业务提示策略等资源完整保留。
- [ ] 通过具名非 root 运行的持久关系数据库和向量数据库访问隔离的真实项目副本，核验数据库进程及持久目录权限和读取与保存；内存数据库、内存向量库和健康检查只作为辅助检查。
- [ ] 缺失文件、错误挂载、额外发布文件、校验不符及错误配置均明确失败；启动脚本和实际启动命令读取同一登记版本。
- [ ] 网页可访问范围与私有数据范围分离，实际请求无法获取密钥、数据库、原件或受限配置；日志只记录脱敏有效值。
- [ ] 在浏览器完成页面进入、一个已有业务请求和保存后重读，核对接口路径、返回和错误含义与基线一致。
- [ ] 保存容器启动、挂载权限、实际请求和重读的可核查证据，并补充本票启动及错误定位步骤；软件检查和真实运行分别记录。
